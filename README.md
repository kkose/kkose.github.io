# kkose.github.io

Personal academic site, built by GitHub Pages from this repo (plain Jekyll, no theme).

Common edits:
- **News:** add an item at the top of `_data/news.yml`
- **Publications:** add an entry to `_data/publications.yml` (`selected: true` puts it on the home page)
- **CV:** replace `files/Kivanc-Kose-CV.pdf`
- **Pages:** `index.md`, `research.md`, `teaching.md`, `personal.md`; nav and links in `_config.yml`

Local preview (optional): `bundle install && bundle exec jekyll serve`
